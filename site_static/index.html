ScienceOS Atlas

Static, daily-updated paper feed for the ScienceOS apps. JSON only; no PDFs are served.

  • index.json — manifest of all feed shards
  • feeds/latest.json — latest day, top papers
  • feeds/trending/latest.json — trailing-week trending
  • status.json — days, categories, counts, last run

Data: arXiv metadata (CC0), OpenAlex (CC0), Hugging Face Daily Papers signals and links. Thumbnails exist only for papers licensed CC BY, CC BY-SA or CC0.
